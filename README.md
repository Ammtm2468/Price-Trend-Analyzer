# Investment Tracker (v1.0) 📈

A custom Python script built from scratch to analyze stock market data using core programming fundamentals (loops, lists, and functions) without external libraries. Developed as a practice project after completing the first 4 parts of the University of Helsinki Python MOOC.

## Features
* **Core Statistics:** Calculates the highest, lowest, average prices, and market volatility based on daily closing prices.
* **Trend Analysis:** Tracks the longest "bullish streak" (consecutive days of price increases).
* **Stock Comparison:** Pits two different stocks against each other to compare overall returns and price stability.

## Roadmap (Next Steps)
